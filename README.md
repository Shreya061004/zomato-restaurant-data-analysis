# Zomato Restaurant Data Analysis

## Overview
An exploratory data analysis project on Zomato restaurant data to understand restaurant trends, ratings, pricing, and delivery patterns.

## Analysis Performed
- Data cleaning and preprocessing
- Restaurant distribution analysis
- Country-wise restaurant analysis
- Rating analysis
- Cost and pricing analysis
- Online delivery analysis
- Relationship between price and ratings
- Restaurant trend visualization

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Files
- `main.ipynb` — Complete data analysis
- `zomato.csv` — Zomato restaurant dataset
- `Country-Code.xlsx` — Country code mapping dataset
